# Composition Guidelines

## General Rules

- Keep important elements away from extreme edges (may be cropped)
- Works as a **background** — don't dominate the frame with a single object
- Leave visual breathing room for UI overlay (text, choices)

## Common Issues to Check

| Issue | Fix |
|-------|-----|
| Text/UI in the image | Regenerate with stronger "no UI" language |
| Subject too close to edge | Add "centered composition" to prompt |
| Too busy/cluttered | Simplify scene description |
| Wrong mood/style | Adjust style keywords, add reference image |

## Prompt Adjustment Tips

If regenerating, try:
- More specific style keywords ("soft diffused lighting", "low-poly geometry")
- Simpler scene descriptions (fewer elements = more control)
- Reference images for consistent style
